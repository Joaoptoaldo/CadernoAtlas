# Instruções para Claude Code

As instruções compartilhadas e operacionais do projeto estão em `AGENTS.md`. Essa é a referência principal para desenvolvimento, decisões arquiteturais, padrões e verificações.

@AGENTS.md

Siga as instruções importadas como referência principal. Antes de editar, verifique o estado atual do repositório com `git status` e preserve todas as alterações preexistentes do usuário. Para mudanças amplas, dependências, arquitetura ou esquema do banco, apresente um plano curto com files afetados, motivo e impactos esperados, e aguarde revisão antes de executar.

O CadernoAtlas está evoluindo para uma **plataforma de organização e planejamento acadêmico adaptativo**. As funcionalidades de concursos e editais permanecem válidas e devem evoluir coerentemente com essa nova visão. Novas funcionalidades devem ser alinhadas com os princípios de produto descritos em `AGENTS.md`, seção 2.
